# 时尚重塑 Skill

把经典形象变成时尚大片主角。支持三种模式：策划（给方向）、摄影（直接出图）、修改（改底图）。

**时尚老沙：把“承担”穿在身上。**

如果一直挑担的人，第一次让衣服替自己撑住肩膀，会是一张什么样的时尚照片？
[先看完整示例：肩上无物、这次不用搬、全场等他](examples/demo-sha-seng.md)。文档保留三份文字策划；第一份提示词已完成真实生图试用，并补测同会话更换背景。

`fashion-remix` 可以先给创意简报与摄影提示词，也可以承接明确的图片请求直接出图、修改已有作品或取回旧版。
只解构或给方向时交文字；拍一张时调用当前可用的内置图像工具；已选方案会原样承接到摄影阶段。
中文名“时尚重塑”，首发概念“时尚老沙”；沙僧、悟空、黛玉及自创角色都可以成为起点。

## 直接这样用

```text
使用 $fashion-remix，为沙僧策划三个原创时尚摄影方向，给简报和提示词，先不生图。
```

```text
使用 $fashion-remix，只解构林黛玉可以进入时尚摄影的线索，暂时不出方案。
```

```text
把最早第2个方案的风衣改成墨绿色，其余保留。
```

```text
使用 $fashion-remix，给沙僧直接拍一张时尚大片，选角和摄影你来定。
```

```text
使用 $fashion-remix，按刚才第2个原创方案出图，保留那套构思。
```

```text
只改R1的背景，人物和衣服保持；请以R1真实图片为底图。
```

```text
回到R1-2之前那一版，直接给我原图。
```

“改第2个方案”改文字，“改R1”改图片；回退原图不重新生成。
有现成参考图时说明是借风格、保持人物还是重塑具体场面；没有图也能开始原创策划。
角色库没有的人物会先起草资料，不要求用户填十字段问卷。

## 安装

版本：`v1.1.1`，包含示例目录修复与同会话修改补测说明。以下命令适用于 macOS / 类 Unix shell；先克隆指定版本，再将受版本控制的24个文件安装到Codex技能目录：

```sh
git clone --branch v1.1.1 --depth 1 'https://github.com/denggui-ai/fashion-remix'
fashion_skill_dir="${CODEX_HOME:-$HOME/.codex}/skills/fashion-remix"
if [ -e "$fashion_skill_dir" ]; then
  echo "目标已存在，请先备份再安装；未覆盖任何文件。"
else
  mkdir -p "$fashion_skill_dir"
  git -C fashion-remix archive v1.1.1 | tar -x -C "$fashion_skill_dir"
fi
```

安装目标是整个 `fashion-remix` 文件夹，主入口位于 `fashion-remix/SKILL.md`。
目标已存在时先保留旧文件再决定更新方式，不盲目覆盖已有修改。
安装后打开新的Codex会话，用上面的显式 `$fashion-remix` 指令检查是否读取该技能。看见目录不等于宿主已发现；未发现时重新加载技能或重启客户端。

## 运行本地示例

```sh
./fashion-remix/scripts/run-demo.sh
./fashion-remix/scripts/run-demo.sh --prompt 2
```

若已进入Skill目录，使用 `./scripts/run-demo.sh`。
默认展示完整示例；`--prompt 1`、`--prompt 2`、`--prompt 3` 只显示对应初始方案的提示词。
从`v1.1.1`起，脚本按自身位置定位示例，Skill文件夹更名、路径含空格或中文、从其他工作目录使用绝对路径运行均可；仅需系统shell、cat和awk，不调用模型、联网或生图。旧版`v1.1.0`仍要求文件夹名为`fashion-remix`。
新创意由Codex读取Skill后策划，不由这个演示脚本自动生成。

52张历史图库不随本包分发；摄影方法已以文字自包含。具体参考图按任务另行取得并确认可用。
旧版 `classic-fashion-director` 应移出可发现的技能目录或放入隐藏父目录；仅改到 `_archived/` 仍可能被Codex发现。本机迁移已使用 `_archived/.disabled/`，原文件保留。

## 运行条件与已验证范围

- 本机验证环境：macOS、Codex CLI 0.155.1及Codex桌面内置图像工具。其他操作系统、最低客户端版本和全新设备安装尚未验证。
- 安装需要Git、tar及GitHub网络访问；文字演示只需shell、cat、awk；任务核对脚本需Python 3标准库。无需安装Python依赖或提供API密钥。
- 文字策划需要可用的Codex模型；摄影与修改还需要宿主内置图像工具和相应账号额度。模型及图像可能消耗套餐额度，费用与可用性以宿主为准。
- 安装只增加技能目录，不自动运行脚本或更改全局配置。文本包小于1 MiB；下载与加载时间取决于网络和宿主，未作时长承诺。
- 本机三句独立新会话检查中，策划与摄影命中本Skill；无上下文“改上一张”命中通用imagegen并要求底图。建议修改时明确使用 `$fashion-remix` 并提供原任务或图片。
- 示例第一提示词最初真实生成一张图片，耗时约75秒；后续补测另生成新的R1（29.704秒），同一持续会话用它更换赛博朋克背景（830.174秒，含等待）。这些是各次实测耗时，不是性能承诺。
- 同会话补测进入本Skill修改模式，真实底图与父版绑定正确，背景替换成功；主体主要造型、姿态、提绳和构图基本保持，但衣料纹理、面部及须发细节有重绘，作品状态为`IMAGES_PARTIAL`。修改模式命中不等于“其他完全不变”，也不把原独立新会话结果改成3/3盲选通过。
- 全新设备发现、升级/回退/卸载全流程仍未实际验证；角色公众辨识、精确同脸、用户审美认可、传播效果及稳定成功率未获验证。本版本不宣称production-ready。

## 隐私、升级与排错

策划文本及使用的图片会交给当前Codex宿主及其模型/图像服务处理；本Skill不提供独立服务，不内置遥测或自动上传脚本。宿主自身的日志、缓存、留存和数据设置由宿主管理，本Skill不承诺其删除时限。请勿把密钥、账号密码或不允许外发的素材作为输入。

作品与接续记录保存在工作区的 `outputs/fashion-remix/<task-id>/`。卸载Skill不会删除作品，也不会自动清除宿主的生成文件或日志。需要清理时先备份要保留的作品，再按宿主功能管理其历史和缓存。

更新前，将旧的整个 `fashion-remix` 文件夹复制或移动到技能目录之外，并保存当前作品目录；确认目标不存在后再安装。需要回退时保留新版副本，再把备份恢复到原技能路径。本次没有任务格式迁移；已有作品仍通过明确的原任务路径接续。停用或卸载可先将Skill目录移出可发现目录并重新加载，确认后再自行处理备份。

安全试用：运行 `./scripts/run-demo.sh --prompt 1`，应只打印“肩上无物”的提示词，不联网或生图。只有策划时使用“先不生图”；要修改却没有底图时，应补原图片或任务入口；缺内置图像工具时只能保留方案，不能把文字当作成片。

问题可提交至 [GitHub Issues](https://github.com/denggui-ai/fashion-remix/issues)。只提供操作系统、Codex版本、所用版本标签、问题步骤和脱敏错误；不要上传密钥、账号标识、私人图片、完整私有提示词或本机用户名路径。

使用发布提交SHA和 `v1.1.1` 标签核对来源；摘要一致只帮助发现内容变化，只有从可信渠道取得的摘要才有校验意义，不能单独证明发布者身份。`released`只表示源码/标签发布与声明检查完成；图片完成、用户认可与生产就绪是不同结论。
