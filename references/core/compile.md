# 从构思到摄影提示词

编译是把方案里的关系写成能被画面呈现的描述，不靠堆砌风格标签。

## 编译顺序

1. 角色及本轮身份依据：只写有依据的形貌与本轮锁定线索。
2. 可见主体关系：谁在哪里、朝向哪里、正在做什么或保持什么姿态。
3. 衣装与道具：剪裁、穿法、材料、与身体的接触关系。
4. 摄影组织：景别、视点、占幅、前后层次、主要光色与材质表现。
5. 保留与变化：身份线索、参考结构、文字约定与允许变化的部分。
6. 去掉只有概念名、没有画面含义的词；检查要求是否相互打架。

镜头焦段可按需要给出，不能把固定焦段或参数当成时尚感的保证。
“高级”“颠覆”“有力量”要落成身体态度、画面关系或光材质；不要求每张增加道具与剧情。
约束以正面限定为主（写“脸部轮廓受光可读”而不是“不要黑脸”）；负面只保留短尾句（卡通、塑料皮肤、多余文字），不写会引入该物的否定句。识别卡写明的结构级排除形态（如“不是精灵尖耳”“不是尖顶王冠”）是允许的短尾句，不受此限。

## 从文字策划交给生图

已选命题、关系和用户锁定项保持；摄影落实时检查哪些描述仍只是类别或意图：

- **身份落到形态。** “头部标识”“经典造型”“有角色辨识”可以作构思提示，不能单独充当生图约束。把本轮重要的面貌、须发、头饰或道具落实为有依据的形状、位置和组合；使用身份图时先实际查看并传入，写清只借哪些部分。通用胡须、珠串等符号齐全，不足以证明人物可辨。已定妆的角色以识别卡的定妆照为身份图，只借识别卡写明的部分（脸、识别物、按衣装模式的衣装），剧照只作结构参考；非人体征与冠帽按识别卡的结构级规格逐条写进提示词，并写明排除形态（例如“不是精灵尖耳”“不是尖顶王冠”）。
- **区分两类依据。** 明确的原创角色设定可以直接用具体文字生成；要呈现熟悉的指定造型，则核对该造型的依据，不以自行补写的细节冒充。沿用任务中仍适用的身份资料，不能因为新衣装、新背景或最终提示词禁用版本名就丢弃它。关键形态未定时，先补可用资料或一个必要的选择，不让图像模型随意填空。
- **衣装和作用关系可见。** 当现代剪裁或受力关系是表达中心时，说明与它有关的领型、开合、材料、连接位置和受力对象。“时尚”“背带”“褶皱”不能独自承担命题；普通静态肖像不为此增加机械结构或剧情。
- **细化留痕。** 保存落实后的提示词、输入职责和相应新卡片快照，保留原稿；参考的古装、场景和姿态不自动继承。若改变了谁承重、谁支撑等核心关系，按下方修订规则同步命题，不能称只是补摄影细节。

生成后核对这些形态和关系的实际呈现；文字自洽、S项齐全与图像目标达成分别记录。不要以一次图像结果推断所有角色都必须有参考图。

## 失败后的修正交接

对已失败的核心目标，在现有requirements里简记四项：原问题、拟改变的可见关系、预期变化、必须保留项。以当前失败图和仍有效的用户要求为依据，说明调整为何可能有效；尚未验证的解释标为假设，不把“已换衣服／已换焦段”当成问题已解决。只记录影响本次决策的关系，不把所有摄影描述升格为硬验收。

提交前将已保存的身份观察与最终提示词对照：本轮重要的形状、位置及组合是否落实，实际引用图的职责是否一致；文本逐字传递不等于观察已完整编译。近景身份图未显示的颈、肩、躯干和体型须标为原创设计选择，不能冒充参考事实或继承其透视比例；用户明确指定的身体条件仍保留。没有图片的原创设定按文字继续，不为这项检查强制补图。

保留旧提示词与失败记录，将新简报和落实后的提示词绑定本轮输出；结果按[修正核对与确认](../director/input-and-qc.md#修正核对与确认)分别检查变化、效果和接受范围。

## 完整方案卡

```text
Q1:1｜短标题
命题／表达意图：这张图希望传达什么。
方向：反差颠覆／气质放大／世界观重塑／情绪人像（四选一，可注明次要）。
风格：风格模板名／经典画面（作品与画面）／原创摄影。
画面：主体、动作、位置、空间与摄影关系。
保留与变换：本轮S/A与B/C的具体取舍。
构思依据：相关轴、系统与受众假设。
选择理由：适合本次目标的原因和与当前其他方向的区别。
提示词：一段可独立使用的完整摄影描述。
看图注意：本张最可能失败的两三处（来自风格入口或摄影方法的“失效表现”）。
待核对：缺失素材、事实或参考，只列影响本轮执行的内容。
```

输出可按用户需要压缩，但标题、可见画面和提示词不能互相矛盾。
以[示例](../../examples/demo-sha-seng.md)理解完整交付（示例为旧版字段，没有“方向”“风格”“看图注意”三项）；不要把示例造型机械套到所有角色。

## 参考与输出

- 实际有图且已经查看，才说它是本轮参考；没有附件不写“如附图”。
- 身份图、摄影参考、经典画面和编辑底图分别说明职责，不能互相冒充。
- 经典场面重塑要指出保留的构图、动作或关系；未核对原画面时注明条件化策划。
- 最终摄影／生图提示词默认不用“86版”等版本指向，也不用“某演员”占位或具体演员姓名替代形貌。把要求落到已核对的可见特征与实际参考图；有真实图片时通过工具支持的引用机制传入，只有资产编号不能冒充已传图。
- 这条规则约束最终提示词，不禁止在检索、身份核对和任务记录中保存真实版本／人物来源；不要因此丢弃用户指定的身份图或同脸要求。没有图就明确按文字条件策划，不伪造身份资产。
- 用户明确要求最终提示词保留某个版本或演员名字，且没有仍有效的冲突禁词时，按其明确要求编译。明确的新指令可以修改旧约定；仅“用这张身份图”不自动解除原禁词。范围确实冲突且无法判定时只澄清冲突点。
- 图片生成尚未发生时，只交文字方案；不把prompt称为成片，不自动计为用户已认可。

## 修订传播到哪里

局部外观变化：只更新相关画面与提示词，保留未受影响的构思。
系统或核心关系变化：同步命题、动作、空间、提示词和当前比较理由。
新一轮仍展示的其他卡片要使用当前候选比较，不能继续比较已移出的旧方向；旧卡原文保留。
同一线索既必须原样保留又被改写时，先处理冲突，不生成两条互斥描述。

编号、旧快照和用户反馈按[记录与恢复](../director/conversation-state.md)保存；方案选择与图像执行分别处理。已选方案转成图沿用同一任务与完整卡片，摄影细化不自动换命题或系统。
