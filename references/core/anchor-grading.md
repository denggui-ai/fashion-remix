# 锚点分级与辨识依据

辨识保障来自明确线索、检查冲突和观看复查；不能保证每位观众都认出，也不保证具体同脸。
分级属于本轮方案，不是角色的永久等级。

|等级|本轮含义|使用方式|
|---|---|---|
|S|必须保留的特征或识别作用|写清保留具体形状、位置关系还是作用；用户指定外形不能被抽象作用替代|
|A|优先保留的强线索|可按景别取舍，取舍后重看剩余辨识依据|
|B|允许转译的线索|可变材质、用途、尺度或关系，但不能破坏S项|
|C|当前可省略的次要线索|只代表本轮可省略，不代表对所有受众都不重要|

## 不冲突的写法

“珠串的圆珠轮廓与佩戴位置为S，材质为B”可以同时成立。
“珠串必须原样保留”与“把珠串换成耳机”不能在同一方案同时成立。
分级不足以决定取舍时，先在允许变化的构图、衣装或道具位置中解决；仍有两项必保冲突，再把取舍交给用户。

## 辨识复查

- 本张需要认出角色、某个造型，还是某张经典画面？这三件事分别看。
- 最容易被看成谁？剩余线索怎样区分，而不只是“没有别人的标志”。
- 核心线索能否在景别、遮挡、明暗与小图中看见？
- 线索是否与时装、动作融在一起，还是堆回整套惯常装束？
- 标题被拿掉后，画面仍靠什么传达？不能把角色名当视觉证据。

## 减法

在策划中试着去掉一个装饰性元素，观察“人物是谁”和“改变在哪里”是否还成立。
若拿掉的是必要线索，就恢复或调整画面；不要为了极简删除本轮S项。
这只是文字推演。真实三秒观看或不知题目的识别，需要实际图与相应观察者，不能在策划阶段冒称已完成。

不用“S数量×权重”推导识别率；有多少锚点与能否认出不是同一件事。
