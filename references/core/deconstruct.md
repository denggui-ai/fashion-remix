# 十字段解构

用于发现角色能进入摄影的线索，不是交给用户填写的表单。
已有角色资料先复用；只展开与本轮创作相关的字段。

|字段|观察重点|沙僧的可用入口|
|---|---|---|
|身份标签|是谁、处于什么角色位置|取经同行者、承担任务者|
|身体符号|面貌、妆发、体态、轮廓|大众造型中的髯须与头部标识，具体形状随依据核对|
|随身道具|原来做什么、与身体怎样相连|担子、行李、珠串等常见联想|
|核心动作|谁对谁做什么、动作有何阻力|挑、扛、等待、跟随、护持|
|叙事功能|在故事关系中承担什么作用|维持同行、执行与支持，可按用户版本调整|
|关系结构|命令、依赖、照顾与被照顾|位于团队中的支持者位置|
|空间归属|地点、边界与秩序|行旅路径、河岸；不是每张都需要水|
|精神内核|有关的态度、愿望与矛盾|沉稳、少言与承担是常见印象，不是唯一性格|
|语言／口头禅|表达方式如何进入画面|少言可转成目光和身体态度；不编造经典台词|
|色彩系统|设定色、服装色与本轮光色|依据不同而变化，不设唯一标准配色|

## 使用方法

1. 把用户提供的设定视为本轮依据，和已有资料明显冲突时先辨明是否有意改写。
2. 标清“用户设定”“资料支持”“常见印象”“本轮创作选择”“未知”。
3. 角色没有专门资料时先自行起草，不要求用户填满十项。
4. 缺口不影响当前画面时保留未知；会改变指定身份或硬性保留项时只补一个关键问题。
5. 进入[锚点分级](anchor-grading.md)，决定哪些线索在本轮真正有用。

完整角色档案可覆盖十项；一次安静肖像只需其中几项。语言与色彩不自动成为字幕或固定滤镜。
“有某物件”不等于角色可辨；留意该物件与其他人物是否共用。
