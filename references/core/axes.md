# 颠覆轴库

轴回答“怎样变化”，不是每次必走的关卡。选一条已能产生好画面就不用凑数。

|轴|思考入口|沙僧的构思示意|
|---|---|---|
|权力反转|谁安排谁、谁等待谁|曾经挑担的人成为决定行李去向的人|
|时空错置|不同年代、节奏或生活机制的碰撞|缓慢步行的人进入秒级运转的分拣现场|
|符号替换|形状与作用怎样保留、材质或用途怎样改变|挑担的肩线转译为西装的结构，不随意替换锁定头部线索|
|人格反转|本轮允许改写的态度怎样变化|被视为少言的人占据发布会唯一话筒|
|系统移植|人物进入什么新的制度或生活关系|随行承担者进入机场自助托运流程|
|媒介转换|谁在观看、画面由何种观看方式形成|把时尚肖像组织成俯视观察的监控式构图|
|尺度缩放|人、物与空间的大小关系怎样改变|一条珠串像巨大的空间边界围住秀场|
|价值倒置|什么被追逐、忽略、珍藏或丢弃|被忽略的挑担肩痕成为服装展示的中心|

这些是创作例子，不是原故事事实，也不是已完成图片。
用户要静态肖像、只借风格或局部修改时，按其范围使用；不为使用轴而额外改写性格或剧情。

## 方向偏好怎样影响选择

先摘出用户的硬约束，再把“更安静、偏街拍、衣装为主”等变成排序理由；没有指定权重时，用“优先／其次／可让步”即可。候选必须先满足用户锁定与本轮S，才进入偏好比较。导演自选S需要调整时，按[锚点规则](anchor-grading.md)说明并修订。

例如“角色要认得出，偏安静，街拍其次”：先检查辨识线索；在可行方向中优先少动作、清楚衣装关系的构思，街景只是次要偏好，不自动要求换掉棚拍或复刻电影。
用户明确给数值时可用 `偏好参考分 = Σ(用户权重 × 本轮有说明的贴合度)`，如安静70%、街拍30%。评分尺度与判断理由一并写明，仅用于本轮取舍；未给权重不自行制造精确分数，未知项不记为满分。它不是审美质量、公众识别率或传播概率，不能让一个违反保留项的方向因得分高而胜出。
候选变化后同步比较理由；不同目标可用不同维度，不固定统一五维总分。
## 卡住时的触发器

- 反向提问：如果惯常做事的人不再做，会发生什么可见变化？
- 极端化：把距离、重量、秩序或安静推到画面能读懂的程度。
- 去神话：让超凡身份进入普通生活细节。
- 再神话：把日常物件或身体姿态拍出仪式性。
- 错位：让人物、用途或观看者出现在不惯常的位置。
- 物化：把一种抽象关系转成空间、衣料或可见物体。

触发器是可选提示，不规定轮数。用[系统库](systems.md)进一步把变化落实到人物的处境。
