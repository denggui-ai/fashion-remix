# 为 fashion-remix 添加角色

目前内置：[沙僧](sha-seng.md)。没有资料的角色也可直接策划，无须先扩充角色库。

## 添加方法

1. 复制 [_template.md](_template.md)，以简短小写拼写命名，例如 `lin-dai-yu.md`。
2. 写明角色名称、来源范围及用户设定；区分文字依据、已看图片、常见印象与创作选择。
3. 按十字段整理已有资料，未知保留未知，不编造台词、唯一面貌或配色。
4. 提供候选锚点与容易混淆的对象；具体S/A/B/C仍由每次创作决定。
5. 给两三个可转译关系示意，避免把一套衣装或一个系统固定成角色唯一解法。
6. 在本页“角色目录”增加链接，让后续调用找得到。

在Codex中可以直接说：“使用 $fashion-remix，依据这些设定添加一个角色资料。”
只有明确要求保存角色时才落盘；一次性策划只需使用任务内的工作草稿。

## 内容核对

确认资料能回答“哪些线索有依据”“哪些可以变化”“容易误认成谁”。
不要求收藏所有资料，也不把文学形象强行归结为唯一具体面孔。
图片来源与使用职责如实写明；链接存在不等于图片已查看。
新增文件后保留现有文件，不以角色扩展为由删旧稿。
