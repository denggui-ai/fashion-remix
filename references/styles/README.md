## 怎样用

- 用户点名模板就直接进入该模板；用户点名经典海报／剧照时本文件不介入；已选方案转成图时模板只补方案没写的机位、支撑与光。
- 每套模板先选定互斥项（一种光、一种机位、有字或无字），再把身份层、衣装与动作填进编译模板；占位符全部填完才是可提交提示词。
- 约束以正面限定为主，负面只留短尾句。
- 每张看图按该模板的“看图重点”说明可见依据，不打总分；比例、面部、鬼感、像不像扮装由用户判定，模型观察只记为主控观察。

## 首选与候选（2026-10-09 v2）

首选四套：L1 街头、L2 居家、F3 车内、F4 广告。F1 保留在库里作来源记录，用户点名才用。自由出图在首选四套里择一并说明。

四套首选的共同规则（Owner 2026-10-09 接受的三张沙僧与三个口味锚点共有的东西）：
- 真实场所，不用纯色棚（F4 的深色棚例外）。
- 人物在做一件具体的小事（看地图、听唱片、喝汽水、吃肉串、等人）。
- 质感：胶片颗粒、自然光、轻微动态模糊或暗角，允许不完美；可选圆角胶片边框＋暗角（老熊饼干 4013 赞那条用过）。
- 身份靠角色识别卡里的固定项，不靠标题。

**衣装模式由角色识别卡声明，模板不替角色决定：**
- 标识固定、衣装随风格：沙僧。衣装是会出现在街上的日常现代衣服（毛衣、麻衬衫、休闲西装、工装），不是礼服、织金、演出服。
- 衣装跟人走、只换场景和光：唐僧、八戒（Owner 2026-10-09 原话）。两人在任何模板里都穿定妆照那套传统衣装，模板只决定场景、光、机位、版式；不要求把他们换成现代衣服。

## F1｜高饱和色块·棚拍杂志

**设计**：极简摄影棚，二到三块高饱和纯色墙地，色块边界平整；正午般的侧上方硬光，人物与道具在墙上投下完整清晰的放大投影；构图平面化、留白明显；中画幅质感，50mm 或 85mm，平视或略低机位；真实皮肤与面料，轻微颗粒。画面由色面、人体、投影三者共同组成。

**四人默认配置**（源配色以案例原句为准）

|角色|墙地|动作与重心|投影重点|
|---|---|---|---|
|悟空|红色运动场式地面加蓝黄白线条，或蓝黄上墙／鲜红地面|躺地松弛，一手伸过头顶，双腿交叉，棒横放，仰视|身体与棒的横向轮廓|
|八戒|明黄上墙、鲜红中墙、深蓝地面|右向大步奔跑，前脚承重，后腿抬起，衣摆后扬|帽、大耳、圆肚、抬腿的侧影落在红墙|
|沙僧|深祖母绿上墙、鲜红下墙、黄地面|拄铲站立，冷峻远望；可换侧身行走扛铲、仰躺铲横胸|铲与人的竖直影|
|唐僧|青绿上墙、鲜红下墙、深红地面|完全侧身站立，冠带垂下|v1 曾以冠帽影为构图重心（1459 复刻被否，v2 不用）；v2 避开帽影压脸，**面部侧轮廓必须受光可读**；衣装按识别卡跟人走|

配色记忆（可用于其他模板）：悟空黄黑、八戒黑红白、唐僧红土黄、沙僧绿紫黑，互不撞色。

**互斥项**：投影为重心／正脸展示；平视／低机位；50／85mm；有字版式／无字。
**衣装路线**：传统衣装（源设定）或现代换装；现代换装不丢色面、硬光、投影和各自动作，否则就是灰棚失败的重演。现代衣装候选取自 F4 四人穿搭。唐僧、八戒按识别卡衣装跟人走，不做现代换装；现代换装只适用沙僧、悟空。
**实现层**：[色面侧跑](../director/photography-methods.md#圆胖身体与图形化动势色面侧跑)、方法 11、08、12。

**编译模板**
```text
真实时尚杂志摄影，极简摄影棚，{竖幅｜横幅}{全身｜膝上}。{角色与身份层：面部、肤质毛发、头部标识的具体形状}。
衣装：{传统：源设定｜现代：剪裁、领型、长度、材料、穿法}；{标识与道具及其与手、肩、身体的接触关系}。
动作：{该角色动作，写清承重与方向}，视线{方向}。
墙地：{上墙色}在上，{下墙或中墙色}在中，{地面色}铺满地面，边界水平平整，{分界高度}。
光：{左｜右}上方硬光，人物在{墙面位置}投下完整清晰的{投影重点}；光同时照到面部{侧轮廓｜正面}，眼鼻口可读。
相机：{平视｜略低}，{50｜85}mm 视角，人物在画面{位置}，{留白位置}，脚与影子完整在画内。
质感：真实皮肤，{主要材料}质感各不相同，轻微颗粒，构图平面化。
{无字｜文字内容、位置}。画面只有这一个人物；不要卡通、塑料皮肤、多余文字与水印。
```
**看图重点**：色面、人体、投影是否组成画面；身份组合在该动作与机位下是否可见；现代衣装剪裁是否可读；唐僧面部是否落入阴影；八戒体量是否被衣服收瘦。

## F2｜黑白纪实·旷野人格

**设计（两版，互斥）**
- A 马匹版：白衬衫、黑西装翻领与领结；左手握深色马的皮缰绳，马头紧贴人物侧脸；戏剧性硬侧光，高反差；85mm 近中景；Vogue editorial 质感。原作（《西行无界》）是彩色街头牵白马，黑白硬光是整理稿的转写，可按任务选彩色版。
- B 乌鸦版：开阔草原或公路、海岸；深色长大衣，双手插袋侧望或缓行；低地平线、大片阴云天空；乌鸦分近中远三层；**柔和阴天光**（对应案例 1409）；低机位竖幅环境肖像。

**用途**：A 靠人与动物的贴近张力；B 靠静止人物与环境动势的对比、小人物与大天空的尺度。B 版不承担反差颠覆目标（见状态表）。
**角色适配**：黑白丢掉颜色，悟空金毛、关羽红面等颜色线索要改由形状线索承担（毛发轮廓、额箍形、须形）；不同角色不共用同一件长大衣与同一站姿，按身份重选肩领、衣量与景别。
**实现层**：[黑白旷野](../director/photography-methods.md#静止人物与环境动势黑白旷野)、方法 08、10。

**编译模板**
```text
黑白纪实时尚摄影。{角色与身份层}。衣装：{肩领、长度、面料；黑白下可区分的明暗关系}。
【A】人物{手握深色马的皮缰绳}，马头贴近其{侧脸}；{左｜右}侧戏剧性硬侧光，高反差；85mm 近中景；背景{阴云下的开阔草地}。
【B】人物稳立于{草原｜公路｜海岸}，{双手插袋侧望｜缓步前行}，{衣摆被风斜向扬起}；低地平线，大片阴云天空；乌鸦近中远三层，近处一两只从画面边缘掠过且不遮挡脸与{头部标识}；柔和阴天光；低机位竖幅环境肖像。
{身份标识}完整可读；真实颗粒，皮肤、毛料与天空灰阶分明。画面只有这一个人物，姿态克制。
```
**看图重点**：人与环境的尺度；动静对照；头部标识与脸在黑白里是否可读；近景鸟是否抢走中心。

## F3｜暖调胶片·车内慵懒

**设计**：红色（或米白）复古轿车后座，红皮座椅，窗外金色田野；身体后靠、宽坐，一臂搭车窗上沿或靠背；日常度假或老钱休闲（亚麻短袖衬衫、米色休闲裤、乐福鞋；或开衫、白T）——沙僧已验证（R3）；唐僧、八戒按识别卡穿定妆那套传统衣装；配饰可选（圆环耳环、戒指、纹身；唐僧、八戒不加现代配饰）；Kodak Portra 400 暖调，35mm，浅景深。案例 1410 的机位是敞开的车门外看进去，金属门框在前层不压脸，光是柔和暖阴天。
**互斥项**：车门外隔框看进去／前排回看后座；开窗／隔玻璃；柔和暖阴天光／低角度斜射夕阳。
**角色适配**：八戒的体量要被座椅真实容纳，不为摆姿势瘦身；唐僧、八戒不换现代衣装；唐僧可肩背靠坐但保持克制，注意五佛冠与车顶的空间；悟空松弛不等于普通年轻男子，妆面与额箍在窗框内可读；暖光不得冲掉身份颜色。
**实现层**：[复古车内](../director/photography-methods.md#正装与私人生活复古车内)、方法 03、04、10。

**编译模板**
```text
暖调胶片时尚摄影，Kodak Portra 400 质感。{角色与身份层}。
衣装：{按识别卡衣装模式：日常度假休闲单品｜定妆照那套传统衣装}；{配饰一两样或无}。
人物坐在{红色｜米白}复古轿车后座，背靠座椅，{一臂搭在车窗上沿或靠背}，双腿{宽坐伸展}，头转向{窗外｜镜头侧方}。
相机在{敞开的车门外，门框与车窗构成前景且不遮脸｜前排回看后座}；红皮座椅与内饰在中层；窗外{金色田野}。
{柔和暖阴天光｜侧窗斜射的低角度暖阳}照到脸和衣料，车内暗部保留层次。35mm 视角，浅景深，皮肤、毛料与皮革质感各异。
{身份标识}在窗框与领口之间清楚可读；{道具：无｜位置}。神态松弛，不做营业表情；画面只有这一个人物。
```
**看图重点**：相机在哪里、框与人的前后关系；身体是否真的被座椅承托；身份标识在窗框里是否可读；暖光有没有吃掉身份颜色。

品牌名默认虚构；项目已用过“CUCCI”（三条路线对比 R1、R2），Owner 未另指定时沿用。

道具转译是待验证的高优先级假说：道具留在画面里，却以现代动作出现，而不是古装战斗装备。墨镜与遮眼产品会遮住眼部身份线索，位置要与身份目标一起决定。
**互斥项**：纯色棚／具体场景；无字主视觉／完整海报；有真实产品／纯人物。
**实现层**：[野性面貌与精密着装](../director/photography-methods.md#野性面貌与精密着装近景时装肖像)、[繁复复古与身体占据](../director/photography-methods.md#繁复复古与身体占据)、[暗椅肖像](../director/photography-methods.md#粗犷面貌与前倾压力暗椅肖像)、编译器“衣装和作用关系可见”。

**编译模板**
```text
高端时尚广告主视觉，{纯色深{午夜蓝绿｜暖棕｜黑灰渐变}摄影棚｜{具体场景}}。{角色与身份层}。
衣装：{该角色的具体衣装：面料、剪裁、穿法}；{配饰与墨镜位置，眼部身份线索保持可见}。
动作：{道具的现代转译动作}，{身体与家具的承托关系}，神情{气质}。
光：{主光位置}的戏剧化棚光，面部与{主要面料}受光，背景暗而分离；{机位、景别}，竖幅 3:4。
版式：{无字｜顶部居中“{虚构品牌名}”，底部白色粗体“{口号}”}。画面只有这一个人物，没有其他品牌标志。
```
**看图重点**：气质是否落在衣料和身体上；道具转译是否一眼可读；文字是否按约定出现；墨镜或产品有没有吃掉身份。

## L1｜街头纪实·人定而周围动

**设计**：真实街道（弄堂口、地铁口、斑马线、红砖墙前），人物静立在画面中部偏下做一件小事（看地图、看手机、等人、点烟），两侧行人以长曝光拖影流过；阴天街光或傍晚冷暖混光；胶片色、颗粒、轻微暗角；35mm，平视，全身或七分身；人小景大但脸可读。
**互斥项**：拖影人群／空街；傍晚冷暖混光／阴天漫射；全身／七分身。
**角色适配**：按识别卡的衣装模式——沙僧日常现代衣装；唐僧、八戒穿定妆那套传统衣装（袈裟、黑袍）站在街头，衣摆可被风带起但不改衣。
**实现层**：[人物识别](../director/photography-methods.md#人物识别)、方法 07（案例 1416／1441，贾莫三道《东海岸西游记》9039 赞的构图）；已验证：沙僧 R1／R1-2。

**编译模板**
```text
竖幅真实生活摄影，纪实或电影剧照的观看感。{角色与身份层：识别卡固定项的具体形状与位置}。
衣装：{按识别卡衣装模式：日常现代单品的剪裁与材料｜定妆照那套传统衣装，逐件写出}。
人物静立在{具体街道}画面中部偏下，{正在做的小事与手的位置}，视线{方向}；两侧行人以长曝光拖影流过，不遮脸。
{傍晚冷暖混光｜阴天漫射光}，湿地面或招牌只剩不可读的光点；35mm，平视，{全身｜七分身}。
胶片颗粒、轻微暗角、真实皮肤纹理，允许不完美；无文字、品牌标志与水印；画面只有这一个清晰人物。
```
**看图重点**：拖影是否成了第二主体；脸与识别物在人群中是否可读；衣装模式是否按识别卡；是否变成了棚拍式摆拍。

## L2｜居家日常·俯拍松弛

**设计**：有人住的家里（瓷砖地、木地板、沙发、床），正上方或高角度俯拍，人物沿竖幅对角线仰躺或蜷坐，手里一件生活物（CD 机、唱片封套、书、遥控器），闭眼或看物不看镜头；自然顶光或窗光；可加圆角胶片边框与暗角；50mm，俯拍。
**互斥项**：正上方俯拍／斜 45° 高角度；仰躺／蜷坐；有边框／无边框。
**角色适配**：同 L1 的衣装模式。八戒优先平视或略俯（斜 45° 高角度）；正上方俯拍须鼻与两耳可见，否则换机位（20261009-idcard-probe R2 正上方俯拍鼻头朝上看不到、一耳被手和物品遮住，Owner 2026-10-10 观察未接受）；体量要被地面或沙发真实承托；唐僧的冠在俯拍下要完整入画、不与地面图案打架。
**实现层**：方法 12（案例 1419，老熊饼干《老沙就是帅啊》4013 赞的俯拍仰卧）；已验证：沙僧 R2。

**编译模板**
```text
竖幅真实生活摄影，正上方俯拍。{角色与身份层：识别卡固定项}。
衣装：{按识别卡衣装模式}。
人物沿画面对角线{仰躺｜蜷坐}在{具体地面或家具，有磨损和日常杂物}，{手里的生活物与动作}，{闭眼｜看物}，神情放松。
{自然顶光｜窗光}，{有｜无}圆角胶片边框与暗角；50mm 俯拍，身体完整在画内。
胶片颗粒、真实皮肤纹理，允许不完美；无文字与水印；画面只有这一个人物。
```
**看图重点**：俯拍透视是否把头部识别物压扁或遮住（八戒：鼻与两耳是否都可见）；体量是否被承托；地面图案是否抢过人物；是否像摆拍。

## 系列编排

- **定妆门：**编排任何角色的系列前，该角色必须已有 Owner 接受的定妆照并在识别卡登记为身份基线；没有的角色先走定妆（见 [角色目录](../characters/README.md#定妆门与识别卡)），不先铺系列。
- 独立组照（默认）：各自生成再排版；可统一光向、色温、机位、留白（源文拼图规范），或保留角色差异光（悟空硬侧光、八戒柔光偏侧、沙僧逆光或低角度、唐僧柔光均匀）；按系列目标二选一。
- 同框合照：同一空间、相互遮挡与共同动作，按[多人规则](../director/creative-direction.md#多人剧照角色位置与互动)处理。站内点赞最高的系列（上游社会_《取经不必 时尚必取》）就是四人同框，所以“永远分开生成”不是站内事实；但同框作品里没有搜到对视、耳语、递东西这类情节互动的对照，项目也只有一例双人“过得去”，情节互动仍低置信。
- 编排思路：同一模板四人一套色板；或四人四方向掺着来（反差型悟空、气质型唐僧、街头型八戒、情绪型沙僧）；或同一角色季节限定。“退役／退休后的生活”可作默认母题之一。
- 单张扩系列至少改变一个表达关系（动作、空间或道具转译），不只换色。
- 系列的身份一致性靠同一份身份依据或用户已认可的身份基线（accepted_scope 含面部），跨图同脸未被证明。

## 艺术方向（可选参考，不作审计否决条款）

源文给出的取舍：唐僧要“禁欲感的高级”，不要“袈裟配运动鞋”；关羽保留“绿与权威感”；妲己的“妖”是疏离、掌控与危险的美，不是暴露；追求“有质感的反差”，不要“廉价的违和”。源文把“沙僧花衬衫金链”列为低级，却把“八戒花衬衫金链”列为港风推荐，可见这些判断依角色气质而定，不是通用禁令。用户选择幽默、夸张或别种审美时按实际作品看。
